# Обогащение данных: курсовая работа

Исследуем, как ручное и синтетическое обогащение данных влияет на качество и устойчивость моделей машинного обучения. Работа ведётся в паре на двух датасетах: текстовых жалобах и фотографиях винных этикеток.

## Датасеты

| Данные | Исходный набор | Задача |
|---|---|---|
| Финансовые жалобы | [Consumer Finance Complaints](https://huggingface.co/datasets/BEE-spoke-data/consumer-finance-complaints) | Классификация текста по четырём темам: взыскание долга, ипотека, банковский счёт, кредитная карта |
| Винные этикетки | [Wine Labels](https://huggingface.co/datasets/LibreYOLO/wine-labels) | Поиск и разметка полей на изображении |

Новые реальные данные собираем отдельно от исходных наборов. URL, дату обращения и условия использования записываем в [реестре для текстов](docs/text/sources.csv) и [реестре для изображений](docs/images/sources.csv).

## Как работаем

1. Отбираем новые данные и готовим задания для Label Studio. Исходные метки не показываем аннотаторам.
2. Оба участника независимо размечают одни и те же объекты по [codebook](docs/text/codebook.md), сохраняя время на каждый объект.
3. Сравниваем разметку, разбираем расхождения и сохраняем согласованные метки.
4. Создаём синтетические данные и оцениваем их качество.
5. Обучаем модели на четырёх вариантах данных: исходные, с ручным обогащением, с синтетическим и с обоими видами обогащения. Сравниваем качество и устойчивость.

## Структура папки

```text

annotations/

  gleb/  вторая независимая разметка
  agreed/       согласованная итоговая разметка
notebooks/    анализ данных
```
